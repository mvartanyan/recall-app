Welcome to Recall

Meeting transcripts, stored on your Mac.

Recall is an open-source alternative to subscription meeting tools. It records meetings, shows live captions, and keeps the finished transcript locally. Recall has no subscription fee. Soniox bills you for transcription. OpenAI bills you for recaps if you choose to use them.

Local conversation archive Local voice profiles Open-source code

Transcription: Soniox provides live captions and the final speaker-separated transcript. OpenAI is optional. Recall contacts OpenAI when you choose Recap.

Provider charges depend on usage and current pricing. Recall adds no fee.

Required for transcription

Connect Soniox

Speech
  1. Create an account or sign in to the Soniox Console.
  2. Open My First Project → API Keys and generate a key.
  3. Add prepaid balance or automatic top-up if your account requires it.
  4. Paste the key into Recall Settings. Recall stores it in a file readable only by your macOS user account.
Optional for recaps

Connect OpenAI

Summaries
  1. Create or sign in to an OpenAI API Platform account.
  2. Add API billing or credits. ChatGPT subscriptions and API billing are separate.
  3. Create a secret key on the API Keys page and paste it into Recall Settings.
  4. Recall contacts OpenAI when you choose Recap.
Provider support

The maintained app uses Soniox and OpenAI.

If you prefer Whisper, Deepgram, Anthropic, or a local model, the relevant native provider module can be replaced in a fork. The desktop interface, local archive, and voice library can remain unchanged.

These buttons open official provider pages in your default browser. Recall stores conversations and speaker identities in its local database. The source and storage format are available for inspection, backup, migration, and modification.
